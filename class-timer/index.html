두 번 탭하면 나가기 · 한 번 탭하면 시작/정지

사용 가이드

시작·정지

  • 시계를 클릭하거나 스페이스바를 누르면 시작·일시정지
  • 초기화는 처음 설정한 시간으로 되돌림

시간 정하기

  • 위쪽 버튼을 누르면 해당 시간으로 맞춰짐 (시작은 시계 클릭)
  • 원형 바(테두리)를 시계 방향으로 돌리듯 드래그하면 분 단위로 늘어나고, 반대로 돌리면 줄어듦 (한 바퀴 = 60분, 최대 180분). PC에서는 창 어디서든 마우스 휠을 굴리면 1분씩, Shift+휠은 5분씩 조절됨 (타이머가 도는 중에는 남은 시간이 늘고 줄어듦, 멈춘 상태에서는 설정 시간이 바뀜)
  • 입력칸: 7 = 7분, 1:30 = 1분 30초, 45초 = 45초 → Enter는 바로 시작, 설정은 시간만 맞춤
  • 창을 클릭한 뒤 숫자 키를 누르고 Enter를 치면 바로 시작 (Esc는 취소)

특정 시각까지

  • "특정 시각까지" 칸에서 시각을 고르고 시작을 누르면, 지금부터 그 시각까지 남은 시간으로 자동 설정되어 바로 시작 (예: 10:12에 11:00을 고르면 48분 타이머)
  • 입력칸에 직접 써도 됨: 14:30까지, @14:30, 오후 2시 30분까지 + Enter
  • 저장하면 프리셋 버튼이 되고, 누를 때마다 그 시점 기준으로 다시 계산됨. 이미 지난 시각은 설정되지 않음
  • 일시정지하거나 분을 조절하면 일반 타이머로 바뀜

순차 타이머

  • 입력칸에 활동 10, 정리 2, 발표 5처럼 쉼표로 이어 쓰고 Enter
  • 단계가 끝나면 짧은 알림음과 함께 다음 단계가 자동 시작되고, 시계 아래에 현재 단계가 표시됨
  • 이름은 생략 가능: 10, 2:30, 5

시간 저장·삭제

  • 입력칸 내용을 저장하면 위쪽 버튼으로 추가됨 (순차 타이머도 가능)
  • 편집을 누르면 버튼마다 ×가 생기고, 누르면 삭제 → 완료로 마침

창 조작

  • 창이 작아지면(가로 360px 또는 세로 430px 이하) 버튼이 사라지고 투명한 원형 시계만 남으며, 창은 정사각형으로 유지됨
  • 시계 안쪽(원형 바 안)을 끌면 창 이동. 화면 가장자리 가까이 가면 자동으로 붙고, 화면 밖으로 나가지 않음
  • 창 위에 마우스를 올리면 테두리가 나타남. 변이나 모서리를 끌면 크기 조절
  • 우클릭 메뉴: 시작·정지, 시간 선택, 항상 위에 표시, 알림음, 전체화면, 사용 가이드, 닫기
  • 마지막 크기와 위치는 다음 실행 때 그대로 복원됨

휴대폰에서 쓸 때

  • 시작할 때 화면 꺼짐을 막아 줌 (브라우저가 허용하는 경우). 화면이 꺼지면 알림음이 늦거나 안 울릴 수 있으므로 타이머 중에는 화면을 켜 둘 것
  • 알림음은 시작 버튼을 누른 뒤부터 울림. 무음 모드에서는 소리 대신 화면 깜빡임·진동(안드로이드)으로 확인
  • 화면을 완전히 끄면 알림이 울리지 않음. 휴대폰에서는 검정 화면 모드로 켜 두는 방식을 권장 (OLED 화면은 검정 부분이 전력을 거의 쓰지 않음)
  • 브라우저 메뉴의 "홈 화면에 추가"로 바로가기를 만들 수 있음

검정 화면 모드

  • "⚫ 검정 화면" 버튼 또는 B 키: 원형 진행 바와 남은 시간만 남기고 나머지는 완전한 검정 화면
  • 한 번 탭: 시작·정지 / 두 번 탭(또는 Esc, B): 모드 종료
  • 이 모드에서는 화면이 꺼지지 않도록 요청함. 종료 시에는 화면 전체가 빨갛게 깜빡임

알림

  • 남은 시간 1분 이하: 진한 빨간색 / 10초 이하: 원이 깜빡임
  • 종료: 시계가 깜빡이고 알림음이 4번 울림 (앱에서는 창이 다른 창 위로 올라옴). 화면을 건드리면 멈춤

단축키

  • Space 시작·정지 · 숫자 + Enter 시간 지정 시작 · F10 항상 위 · F11 전체화면 · F1 사용 가이드
